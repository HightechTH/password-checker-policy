# Password Checker Policy

โปรแกรมตรวจสอบความปลอดภัยและนโยบายของรหัสผ่าน (Password Policy Checker) ด้วยภาษา Python

## นโยบายการตรวจสอบรหัสผ่าน (Password Policy)
1. ความยาวมากกว่า 8 ตัวอักษร
2. มีตัวอักษรพิมพ์ใหญ่อย่างน้อย 1 ตัว (`A-Z`)
3. มีตัวอักษรพิมพ์เล็กอย่างน้อย 1 ตัว (`a-z`)
4. มีตัวเลขอย่างน้อย 1 ตัว (`0-9`)
5. มีอักขระพิเศษอย่างน้อย 1 ตัว (`!@#$%^&*()-_=+[]{};:,.?`)

## วิธีการรันโปรแกรม
```bash
python password_checker.py
```
หรือ
```bash
python main.py
```
